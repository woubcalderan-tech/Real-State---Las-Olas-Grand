Las Olas Grand Unit 2010 — website pages
=========================================

A ready-to-host static website: 6 HTML pages, one stylesheet, one small script, and 48 edited photos.

  *-es.html         Spanish copy of every page (index-es.html, residence-es.html, ...)
                    The EN / ES button at the top of every page switches to the same page in the other language.
  index.html        Home: hero photo, price, key facts, description, rare-position highlights
  residence.html    Living and dining, kitchen, primary suite, second bedroom, entry
  terrace.html      The 703 sq ft ocean terrace and views
  resort.html       Building grounds and amenities
  value.html        Price-per-square-foot comparison (other units shown as Comparable A-D, no unit numbers)
  details.html      Specs from the deed, features, location
  style.css         All styling (colors and fonts at the top)
  site.js           Click-to-enlarge photo viewer
  images/           48 photos, edited and resized to 1600 px

Every page ends with the contact section: listing agent Perla Espinoza (PD Realty) and the owner, Solange.
To publish: upload the whole folder to any static host (Netlify, GitHub Pages, Squarespace/Wix custom code, etc.).
Open index.html in a browser to preview locally.
